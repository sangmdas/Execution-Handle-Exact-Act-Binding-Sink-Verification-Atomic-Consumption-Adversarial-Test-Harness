# Contributing

Contributions that challenge assumptions are welcome.

1. Add or modify a test that demonstrates the issue.
2. Keep the test deterministic where possible.
3. State whether the issue falsifies the strict invariant, narrows a deployment assumption, or exposes an underspecified profile.
4. Avoid turning adjacent standards into straw men; compare concrete required properties.
5. Preserve raw result files for performance or interoperability claims.
